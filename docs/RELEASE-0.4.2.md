# Markdown Magic 0.4.2

Enthält alle Verbesserungen aus [0.4.1](https://github.com/MediaPublishing/markdown-magic/releases/tag/v0.4.1): Chatbot-Symbol direkt an der Absatzmarkierung, dauerhaft gespeicherte Vorschläge und Verbindungsverwaltung pro Anbieter.

Der direkte Test mit einem vollständig markierten Absatz hat zusätzlich eine Formatierungsgrenze aufgedeckt. Vollständig ausgewählte Absätze schließen jetzt ihre Fett- und Kursivformatierung mit ein. So lässt sich der ganze Absatz ersetzen, ohne einzelne Markdown-Zeichen zurückzulassen. Auswahl innerhalb eines formatierten Wortes bleibt wie bisher möglich. Die Einstellungen zeigen den aktuellen Verbindungsstatus nur in der jeweiligen Anbieterzeile, statt daneben einen veralteten Zwischenstand anzuzeigen.

Includes all [0.4.1 improvements](https://github.com/MediaPublishing/markdown-magic/releases/tag/v0.4.1): the paragraph chatbot icon, saved suggestions and individual provider connection settings.

Fully selected paragraphs now include their bold and italic boundaries, so replacing a paragraph does not leave Markdown delimiters behind. Partial selections retain their existing behavior. Settings show connection status in the provider's own row instead of repeating a stale initial summary.

Apple Silicon, macOS 13+. Ad hoc signed beta, not notarized by Apple.
