# Markdown Magic 0.2.5 Beta

## Deutsch

- Das Titelmenü zeigt nun nur die passenden Dokumentaktionen, übersichtlich gruppiert. Bei einem unbenannten Entwurf steht das spätere Benennen im Vordergrund; Aktionen für eine bereits abgelegte Datei erscheinen erst danach. „Dokument schließen“ bleibt auch in kleineren Fenstern ohne Scrollen erreichbar.
- Gleichnamige Dateien in „Zuletzt“ zeigen ihren Ordner unter dem Dateinamen. Per Rechtsklick lassen sie sich öffnen, im Finder zeigen, als vollständiger Pfad kopieren oder aus der Liste entfernen. Das Kontextmenü anderer Dateien bietet dieselben Pfadaktionen ohne „Aus Liste entfernen“.
- „Liste leeren“ benennt die Wirkung eindeutig. Die Dateien selbst werden dabei nicht gelöscht.

Alle Neuerungen aus [0.2.4](RELEASE-0.2.4.md) bleiben enthalten. Apple Silicon, macOS 13+. Weiterhin ad-hoc signierte Beta ohne Apple-Notarisierung; Updates werden manuell installiert.

## English

- The document title menu now groups only relevant actions. Untitled drafts put naming first; actions for a named file appear after it has been filed. Close document remains visible without scrolling in smaller windows.
- Recent files show their containing folder to distinguish duplicate names. Right-click to open, reveal in Finder, copy the full path, or remove an entry from the list. Other file context menus expose the path actions without the list-only removal.
- “Clear list” makes clear that it clears the list, not the files.

Includes all changes from [0.2.4](RELEASE-0.2.4.md). Apple Silicon, macOS 13+. This remains an ad-hoc signed beta without Apple notarization; updates are installed manually.
