# Markdown Magic 0.3.0 Beta

## Deutsch

- **Benannte Fassungen:** Wichtige Arbeitsstände über den Dokumenttitel festhalten und ihre Änderungen gegenüber dem aktuellen Text vergleichen. Benannte Fassungen bleiben zusätzlich zu den letzten 50 automatischen Sicherungen erhalten.
- **Passage besprechen:** Text im formatierten Editor oder Quelltext markieren und ⇧⌘K drücken. Das Seitenpanel zeigt den konkreten Ausschnitt. „Nur notieren“ hält einen lokalen Kommentar fest; „Senden“ fragt den vorhandenen Assistenten.
- **Gezielte Vorschläge:** Eine Passagenänderung ersetzt nur den besprochenen Bereich. Unabhängige Änderungen bleiben erhalten; ein veränderter Zielbereich wird nicht blind überschrieben. Erkennbare unvollständige Inline-Formatierung wird vor der Übernahme abgefangen.
- **Dauerhafte Gespräche:** Notizen und Gespräche überleben Neustarts. Titel lassen sich ändern, Kommentare erledigen und wieder öffnen. Beim Bewegen und Benennen bleiben sie erhalten; Dokumentkopien übernehmen sie nicht automatisch. Die Daten liegen lokal im App-Datenordner, nicht als Begleitdateien neben dem Dokument.
- **Ruhigeres Lektorat:** Das Seitenpanel steht in breiten Fenstern neben dem Text. In kleinen Fenstern lässt es sich als schwebendes Panel schließen. Notieren und Senden sind getrennte Aktionen.
- **Bestehender Codex-Zugang:** Der Assistent respektiert die Modellvorgabe der lokalen Codex-Installation anstelle einer historischen festen Modellbezeichnung. Es wurde kein neuer Anbieter ergänzt.

Die Datei bleibt normales Markdown. Kommentare und Historie sind lokal; beim Weitergeben einer Markdown-Datei werden sie nicht mitgesendet. Bei nicht mehr eindeutig zuordenbaren Passagen zeigt die App den verlorenen oder veränderten Bezug. Eine neue Auswahl ermöglicht ein neues Gespräch.

Apple Silicon, macOS 13+. Ad-hoc signierte Beta, weiterhin ohne Apple-Notarisierung und mit manueller Installation von Updates.

## English

- Capture named versions from the document title and compare them with current writing. Named milestones remain alongside the latest 50 automatic backups.
- Select a passage in formatted or source view and press ⇧⌘K. Keep a local note or send that passage to the existing assistant. Apply proposals explicitly; unrelated edits remain intact and changed targets are rejected.
- Conversations survive restarts. Rename, resolve and reopen them. Moving or naming a document preserves conversations; document copies do not inherit them automatically. Notes stay in local app data, without sidecar files in shared folders.
- A calmer review panel docks beside the text in wide windows and floats with an explicit close control in compact windows. Keeping a note and sending a request are separate actions.
- The assistant respects the installed Codex model configuration. No new AI provider was added.

Markdown remains portable. Notes and version history stay local when sharing a Markdown file. Ambiguous or changed passage references are shown rather than guessed.

Apple Silicon, macOS 13+. Ad-hoc signed beta, not Apple-notarized; updates remain manual.
