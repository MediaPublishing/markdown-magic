# Markdown Magic 0.4.3

Markdown Magic ist jetzt mit unserer Apple Developer ID signiert und von Apple notarisiert. App und Installationspaket bestehen die Gatekeeper-Prüfung. Die Apple-Tickets sind angeheftet, sodass die Prüfung auch offline möglich ist.

Enthält die Verbesserungen aus 0.4.2: Chatbot-Symbol an markierten Absätzen, dauerhaft gespeicherte AI-Vorschläge und separate Verbindungsverwaltung für Claude und ChatGPT. Bestehende Dokumente und lokale App-Daten bleiben erhalten.

Markdown Magic is now signed with our Apple Developer ID and notarized by Apple. The app and DMG pass Gatekeeper verification, with notarization tickets attached for offline verification.

Includes the 0.4.2 improvements: the paragraph chatbot action, persistent AI suggestions and individual Claude/ChatGPT connection settings. Existing documents and local app data are preserved.

Apple Silicon, macOS 13+. Updates are installed manually from the DMG. SHA-256 checksums are included with this release.
