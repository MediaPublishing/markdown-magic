# Markdown Magic 0.2.2 Beta

## Deutsch

- Bei einem Dateikonflikt lässt sich ein Tab jetzt ohne Speichern schließen. Der Dialog warnt vor dem Verlust eigener ungespeicherter Änderungen; „Abbrechen“ behält sie. Die extern aktualisierte Datei bleibt unverändert.
- Der aktive Eintrag in der Seitenleiste ist im dunklen Design besser lesbar. Das gilt auch für ausgewählte Ordner und Dokumente.

Alle Neuerungen aus [0.2.1](RELEASE-0.2.1.md) bleiben enthalten. Apple Silicon, macOS 13+. Weiterhin ad-hoc signierte Beta ohne Apple-Notarisierung; Updates werden manuell installiert.

## English

- Tabs with file conflicts can now be closed without saving. The dialog warns that local unsaved edits will be lost; Cancel keeps them. The externally updated file remains untouched.
- Active sidebar entries are easier to read in dark mode, including selected folders and documents.

Includes all changes from [0.2.1](RELEASE-0.2.1.md). Apple Silicon, macOS 13+. This remains an ad-hoc signed beta without Apple notarization; updates are installed manually.
