# Markdown Magic 0.2.3 Beta

## Deutsch

- Markdown-Dateien mit YAML-Metadaten öffnen sich jetzt formatiert. Beim visuellen Bearbeiten bleiben die Metadaten exakt erhalten und lassen sich in der Quelltextansicht bearbeiten.
- In der Dokumentleiste und im Titelmenü lässt sich pro geöffnetem Markdown-Dokument zwischen „Formatiert“ und „Quelltext“ wechseln. Die gewählte Ansicht bleibt beim Tabwechsel und Neustart erhalten. Dateien mit Strukturen, die der visuelle Editor nicht verlustfrei bearbeiten kann, bleiben geschützt in der Quelltextansicht.
- Das Tab-Kontextmenü und das Titelmenü bieten „Dateipfad kopieren“. Kopiert wird der vollständige lokale Pfad als reiner Text.

Alle Neuerungen aus [0.2.2](RELEASE-0.2.2.md) bleiben enthalten. Apple Silicon, macOS 13+. Weiterhin ad-hoc signierte Beta ohne Apple-Notarisierung; Updates werden manuell installiert.

## English

- Markdown files with YAML frontmatter now open in formatted view. Visual editing preserves the metadata exactly; source view remains available for editing it.
- Each open Markdown document has a Formatted/Source switch in the document bar and title menu. Its choice survives tab switches and app restarts. Files with structures the visual editor cannot edit losslessly stay in source view.
- The tab context menu and title menu can copy the complete local file path as plain text.

Includes all changes from [0.2.2](RELEASE-0.2.2.md). Apple Silicon, macOS 13+. This remains an ad-hoc signed beta without Apple notarization; updates are installed manually.
