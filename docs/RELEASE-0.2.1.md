# Markdown Magic 0.2.1 Beta

## Deutsch

- Die Schließen-Schaltfläche sitzt jetzt vertikal mittig in jedem Tab. Das X verwendet ein scharfes SVG-Symbol und behält seine Ausrichtung bei langen Dateinamen.
- Die Website enthält passende Favicons in 16 und 32 Pixeln sowie eine ICO-Datei.

Alle Neuerungen aus [0.2.0](RELEASE-0.2.0.md) bleiben enthalten. Apple Silicon, macOS 13+. Weiterhin ad-hoc signierte Beta ohne Apple-Notarisierung; Updates werden manuell installiert.

## English

- Tab close buttons are vertically centered. A crisp SVG icon keeps the X aligned, including beside long filenames.
- The website includes dedicated 16- and 32-pixel favicon assets and an ICO file.

Includes all changes from [0.2.0](RELEASE-0.2.0.md). Apple Silicon, macOS 13+. This remains an ad-hoc signed beta without Apple notarization; updates are installed manually.
