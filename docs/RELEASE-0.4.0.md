# Markdown Magic 0.4.0

## Deutsch

- Claude oder ChatGPT direkt im Dokument verwenden, mit dem eigenen Abo über die offizielle lokale Claude-Code- beziehungsweise Codex-Anwendung.
- Anbieter im Assistenten auswählen. Die Wahl bleibt nach einem Neustart erhalten. Verbindungsstatus, Installation und Anmeldung sind direkt erreichbar.
- Markierte Passagen oder ganze Dokumente kürzen, umformulieren, übersetzen und besprechen. Vorschläge zuerst vergleichen, anschließend übernehmen oder verwerfen. Rückgängig bleibt erhalten.
- Antworten behalten ihren Anbieter, auch wenn du später wechselst. Bei einem Fehler wechselt die App nicht still zu einem anderen Anbieter.
- Lokale Notizen und Werkzeuge funktionieren weiterhin ohne Konto. Dokumentinhalt wird nur beim Senden übergeben; Zugangsdaten bleiben beim offiziellen Programm. Abo-Limits gelten weiter.

Voraussetzung für Online-Funktionen: aktuelle offizielle Claude-Code- oder Codex-Installation mit Abo-Anmeldung. Die App richtet keinen eigenen API-Zugang ein. Apple Silicon, macOS 13+. Die Beta ist ad hoc signiert und nicht von Apple notarisiert.

## English

- Use Claude or ChatGPT inside your document with your own subscription through the installed official Claude Code or Codex application.
- Choose a provider and keep that choice across restarts. Check its connection or open installation and sign-in directly from the panel.
- Shorten, rephrase, translate or discuss a selection or full document. Compare suggestions before applying or discarding them, with Undo preserved.
- Replies retain their provider label after switching. Errors never silently reroute requests to another provider.
- Local notes and tools still work without an account. Text is shared only on Send; credentials stay with the official program. Subscription limits apply.

Online features require a current official Claude Code or Codex installation signed in with a subscription. No API account is set up by the app. Apple silicon, macOS 13+. Ad hoc signed beta, not notarized by Apple.

Authentication references: [Claude Code](https://code.claude.com/docs/en/legal-and-compliance), [Codex](https://developers.openai.com/codex/auth/). No upstream MAID implementation code is included.
