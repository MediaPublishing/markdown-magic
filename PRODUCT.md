# Markdown Magic

Register: product (desktop application); brand (public bilingual website).

People who write notes, articles and everyday documents on a Mac should be able to start immediately, trust that their text is saved, and find it again. Markdown is a portable format underneath a visual editor, not something a new user must learn first.

The approved direction is a calm Mac document editor with a lightweight local library. New documents are automatic local drafts; naming and filing happen later in a native save sheet. Closing is never deleting. Existing Finder files stay where they belong. No account or AI setup is required to write.

The primary action is New document, followed by Open document. The library has Recent, Drafts, Favorites and Places. The document title owns naming, moving, copying, history and export. Formatting stays visible and approachable. Groups and AI are optional. Preserve existing local files and user preferences.

Tone: clear, helpful and concise; German and English; use familiar platform vocabulary and proper German umlauts. Errors explain a recovery action. Never say Saved before durable write confirmation.

Anti-references: developer IDE chrome, dashboard cards, compulsory onboarding, mandatory folders or filenames before writing, duplicate assistant buttons, proprietary lock-in, invented security or notarization claims.

Reference: the approved September 2026 document-lifecycle concept. Retain Electron, Milkdown and Lucide; no new UI framework or external component dependency is needed. The Apple reference informs behavior; the persistent Drafts library is our deliberate addition.
