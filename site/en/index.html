Before you download

A few useful answers.

Do I need to know Markdown?

Edit headings, lists and other formatting in the visual editor. Source view is available for special Markdown structures. Unsupported content opens there so it can be preserved.

Do I need an AI account?

Not for writing, local comments or saved versions. Choose Claude or ChatGPT for online suggestions. Install Claude Code or Codex on your Mac and sign in there with your subscription. Your plan limits still apply. Only Send shares the text and conversation; passage requests send only the selection. Sign-in stays in the official program.

What happens to comments when I share a file?

Notes, conversations and versions live in local app data. The Markdown file contains only your writing. Conversations are not automatically included when sharing a file or creating a document copy.

Which Macs can run the beta?

Markdown Magic 0.4.2 supports Apple silicon and macOS 13 or later. The beta is ad hoc signed and not yet notarized by Apple. Updates are currently installed manually.
