# Security

## Deutsch

Bitte veröffentlichen Sie mögliche Sicherheitsprobleme nicht als öffentliches GitHub-Issue. Nutzen Sie stattdessen die private Funktion **Report a vulnerability** im Bereich **Security** dieses Repositories und beschreiben Sie Auswirkung, betroffene Version und nachvollziehbare Schritte.

Teilen Sie keine echten Dokumente, Zugangsdaten oder persönlichen Dateipfade. Verwenden Sie für Beispiele ausschliesslich neutrale Testdaten.

## English

Please do not disclose potential security issues in a public GitHub issue. Use the private **Report a vulnerability** option in the repository's **Security** section and include the impact, affected version, and reproducible steps.

Do not share real documents, credentials, or personal file paths. Use neutral test data in all examples.
